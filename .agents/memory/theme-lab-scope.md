---
name: Theme Lab scope
description: Owner-approved isolation boundary for experimental window themes and fonts.
---

Experimental themes and font choices belong inside an admin-only Theme Lab preview, not across the administrator's real desktop or the public site.

**Why:** When offered isolated, temporary whole-desktop, or combined previews, the owner explicitly chose “Inside the Theme Lab only.”

**How to apply:** Keep preview styling and test interactions local. Do not change global typography, user display preferences, shared site settings, or real window state when trying a theme. Making a tested theme available on the real site requires a separate request.
